# Issue tracker: GitHub

Issues for this repo live in GitHub Issues on `rsitman/itmportal`. Use the `gh` CLI for all operations.

## Conventions

- **Create an issue**: `gh issue create --title "..." --body "..."`
- **Read an issue**: `gh issue view --comments`
- **List issues**: `gh issue list --state open`
- **Comment on an issue**: `gh issue comment --body "..."`
- **Close**: `gh issue close --comment "..."`

## Pull requests as a triage surface

**PRs as a request surface: no.**

This repo does not use `/triage` or external-PR triage workflows.
